      启用 Host（留空=任意） URL 前缀 路由方式 目标地址（仅「改道」需要） 探测 状态 操作

      规则匹配浏览器实际请求的 host + 路径前缀；host 留空表示任意。 若前端通过 dev server 代理，请填前端域名（如 localhost:5173）。 HTTPS 页面不能改道到 http 本地地址。
      路由方式「改道到目标地址」= 把请求转发到目标地址，并自动补 CORS/预检（目标可以在本机，也可以在远端）。 路由方式「原样透传」= 不拦截、不改道、不补 CORS，请求直接发给它原本要访问的地址；不需要目标地址。 目标地址只对「改道」生效，填完整 baseUrl（含端口），例如 http://localhost:8080。
