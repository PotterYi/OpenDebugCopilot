## 3. 工程规则（摘要）

完整规则见仓库根目录 [CLAUDE.md](../CLAUDE.md)，以下是摘要：

1. 所有临时文件（验证用或功能需要）统一放在仓库根目录 `.tmp/` 下。
2. 同一批临时文件用一个文件夹包住，文件夹名简要说明这批文件的用途，如 `.tmp/proxy-latency-check/`。
3. 正式项目代码不得引用临时文件中的代码。
4. 判断后续用不上的临时文件及时删除；需要留档的，写成独立文档放到 `docs/` 并在索引登记，不保留临时文件。
5. 文档单文件不超过 500 行；超长即拆分编号，并更新本索引。
6. 开发前必须先与需求方确认开发方案和本次开发内容，确认后再动代码。

## 4. 文档规范

1. 单文档 ≤ 500 行；接近上限（450 行）时即规划拆分。
2. 每篇文档顶部保留索引回链与上下篇链接。
3. 章节编号在单篇内保持稳定，便于引用；新增内容追加到对应章节末尾。
4. 未定论的内容用 **【待补充 Tn】** / **【待确认 Qn】** 标记，并登记到 06 文档。
5. 设计意图与当前实现如有偏差，分开写，不混在一段里。
