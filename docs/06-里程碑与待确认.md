## 11. 待确认与待补充清单

### 11.1 待确认（需要拍板）

| ID | 问题 | 影响面 | 当前倾向 |
| --- | --- | --- | --- |
| Q1 | 桌面框架选型 | 全量架构 | ✅ 已确认：Electron（WebContentsView + CDP），另有 CLI / WebUI 两种入口 |
| Q2 | 内嵌浏览器与代理通道 | 拦截方案、HTTPS | ✅ 已确认：WebContentsView 内置 Chromium，无 MITM 代理；路由走 webRequest 钩子 / dev server 代理 |
| Q3 | 首期支持的语言/框架范围（Java Spring / Node / Go / Python）？ | 堆栈映射、日志模板 | 待定 |

| Q5 | 是否支持非浏览器客户端（移动端、小程序）流量接入？ | 代理方案 | 暂不支持 |
| Q6 | 规则是否需要团队共享 / 云端同步？ | 存储、账号体系 | 暂不需要 |

| Q9 | 单机多工作区是否允许同时运行（多浏览器实例并发）？ | 资源与状态模型 | 允许切换，不并发 |
