## 8.1 三种运行形态，共用一套编排

| 形态 | 入口 | 本地服务在哪 | 浏览器载体 |
| --- | --- | --- | --- |
| CLI | 命令行直接运行 | 服务即 CLI 进程本身 | **无内嵌浏览器**；场景声明 browser 时用无头 Edge 驱动 |
| 本地 WebUI | CLI 进程内起 HTTP 服务，用户浏览器访问 | 同一 CLI 进程 | **无内嵌浏览器**；同上 |
| 桌面版 | **Electron 45** 应用 | Electron 主进程内起同一个 HTTP 服务，随窗口生灭 | WebContentsView（真实 Chromium） |

- 三种形态**共用同一套诊断编排**，不是三份实现。
- **没有独立守护进程**：进程退出，服务即消失；桌面形态不存在后台常驻服务。
- **UI 零框架**：手写 HTML + JS；WebUI 由 Node http server 提供页面与 `/api/*`。
- **桌面复用同一套页面**：Electron 45 加载该页面，通过 **5 个 `dc:*` IPC 通道**与主进程通信
  （通道名称与职责待补，见 06 T20）。
- **playwright-core 只用于无头驱动**，桌面内嵌浏览器走 WebContentsView + CDP。

## 8.2 进程模型

```
[CLI / WebUI]                        [Desktop]
node (ESM)                           Electron main
├─ HTTP 服务（WebUI 形态）           ├─ 同一个 HTTP 服务
├─ MCP 工具（进程内）                ├─ MCP 工具（进程内）
├─ playwright-core → 无头 Edge       ├─ WebContentsView（Chromium）
└─ claude（子进程，SDK 拉起）        └─ claude（子进程，SDK 拉起）
```

- MCP 工具为**进程内**实现，不另起服务、不装外部 MCP server。
- **唯一子进程**：Claude Agent SDK 拉起的 Claude Code。

## 8.3 浏览器与请求捕获：两条独立路径

| 路径 | 载体 / 驱动 | 捕获方式 | 是否重放 |
| --- | --- | --- | --- |
| 桌面版 | Electron `WebContentsView`（真实 Chromium） | **CDP** | **不重放**；列表中点哪条就以哪条为诊断对象 |
| CLI / Web 的 browser 场景 | `src/driver/browser.mjs` + **playwright-core 拉起无头 Edge** | `page.on('request' / 'response' / 'requestfailed')` | **按场景重放**：打开页面 → 执行 actions → 收集请求与响应 |

- “CDP 捕获”只属于桌面版内嵌视图这一条路，不是全局机制。
- CLI / Web 形态没有内嵌界面，browser 场景是“脚本化走一遍页面”来拿到可诊断的请求。

## 8.4 路由控制：webRequest 三钩子（桌面主方案）

| 钩子 | 过滤条件挂的 Origin | 职责 |
| --- | --- | --- |
| `onBeforeRequest` | 宿主 origin | 改写目标路由 → 走本地端口 |
| `onBeforeSendHeaders` | 本地 origin | 抓预检（OPTIONS）携带的头 |
| `onHeadersReceived` | 本机 origin | 补 CORS 响应头 |

- 改道方式：**按 URL 前缀逐条改道**，命中即改目标，未命中原样放行；不做 MITM 代理。
- 预检被单独处理：预检头在 `onBeforeSendHeaders` 采集，响应侧在 `onHeadersReceived` 补齐 CORS，避免跨域失败。
- 前缀规则的配置形态与持久化：**【待补充 T2】**

## 8.5 场景文件与驱动选择

场景文件中可声明 **browser 块**：

| 字段 | 含义 |
| --- | --- |
| `path` | 页面路径 |
| `match` | URL **子串**匹配，用于把请求归属到该场景 |
| `actions[]` | 仅支持 **click / fill** 两种动作，元素定位使用 playwright 选择器；**不支持 select** |

驱动选择规则：

| 场景声明 | 走的驱动 |
| --- | --- |
| 有 `browser` 块 | 浏览器驱动（playwright-core + 无头 Edge） |
| 有 `method` / `path`（HTTP 声明） | HTTP 驱动 |
| 两类声明同时出现等歧义情况 | **直接报错**，不做猜测 |

## 8.6 备用方案：自建壳 + dev server 代理（可能淘汰）

## 8.7 诊断链路与产物

```
预检（preflight）
  → 驱动 fire：拿到请求 / 响应 / 时刻 / marker
  → 注入 marker（可注入时）；等日志落盘（固定 sleep 1.2s）
  → 组装 prompt
  → agent 循环调用证据工具（上限 24 轮）
  → 产出 DiagnosisResult
  → 白名单投影生成脱敏报告
```

### DiagnosisResult 组成

| 段 | 内容 |
| --- | --- |
| 元数据 | 会话 / 场景 / 时间 / 模型等运行信息 |
| target | 本次诊断的目标标识 |
| 请求 / 响应 | 原始请求与响应内容 |
| marker 披露 | 是否注入、注入字段、marker 值 |
| 时间窗统计 | 窗口内日志等统计信息 |
| agent 段 | 结论原文 + 证据链（每条证据含工具参数与返回原文） |

### 脱敏报告：白名单投影

- 生成方式：**先白名单投影，再渲染**（不是先渲染再删敏感信息）。
- 保留字段：目标名 / 症状 / 耗时 / 结论 / 请求 / 摘要 / 工具计数 / 自检。
- 去除内容：**绝对路径、头值、日志与源码原文**。
- 报告形态（UI 渲染 / Markdown 落盘 / 分享）与“自检”的具体检查项：**【待补充 T17】**

### 稳定性：硬闸门 + n=3 多次判定

| 机制 | 含义 |
| --- | --- |
| 硬闸门 | agent 是非确定性的，因此**代码能保证的部分用硬闸门判定**（不依赖模型自觉） |
| 多次判定 | 同一场景跑 **n = 3** 次，逐次比对，记录「一致 / 不一致 / 判不了」 |
| 判定语义 | **单次 agent 结论不作为通过条件**；结论需在多轮间经受住比对 |
| 界面呈现 | 明确展示“**一致不等于正确**”，避免把一致性当成正确性背书 |

- 硬闸门的**具体条目**（哪些检查算硬门）、n 是否可配、不一致时的兜底动作：**【待确认 T11】**

## 8.8 marker 与日志落盘

| 项 | 现状 |
| --- | --- |
| marker 形态 | `dcprobe` + 随机 hex |
| 注入位置 | 请求 body 中“**会被日志回显、但不参与业务**”的字段（安全字段） |
| 匹配方式 | agent 调用 `get_logs({ marker })`，按**子串**匹配日志内容 |
| 无安全字段时 | **不注入**，并在 prompt 中明确说明（避免模型臆造关联） |
| 落盘判定 | **固定 sleep 1.2s**；实测链路延迟约 150ms，留出冗余 |

- 固定等待实现简单，但在慢系统/高负载下存在截断风险，是否改为轮询或事件驱动：**【待确认 T18】**

## 8.9 证据底座：日志采集与工具

### 日志采集（当前实现）

| 项 | 现状 |
| --- | --- |
| 数据源 | **纯读 `logfiles` 声明的文件**，不 attach / 不碰目标进程 |
| 读取方式 | 流式 `readline`；编码用 `iconv-lite`，支持 GBK；编码可配 `auto / utf8 / gbk` |
| 轮转 | 识别同目录下的轮转文件（如 `app.log`、`app.log.1`） |
| 多行 | 聚合堆栈续行，归并到上一条记录 |
| 解析 | 预设或自定义 regex |
| 自动探测 | 判据：**命中率 > 60% 且全部可解析**；不满足则报错，不猜（不设默认兜底格式） |
| 查询 | **每次调用全量线性扫**，不维护索引/offset |

### 工具（MCP，进程内）

| 工具 | 作用 | 关键入参 |
| --- | --- | --- |
| `get_logs` | 按条件检索日志；支持按 marker 子串匹配 | 时间窗 / 线程 / marker / 标记 / 级别 |
| `list_threads` | 窗口内线程直方图，判断请求落在哪个线程 | 时间窗 |
| `search_log` | **全库**关键词检索，不限时间窗 | 关键词（用于找“只打一次”的降级日志） |
| `read_source` | 按类名或路径读取源码 | 类名 / 路径 / 行区间；**同名返回候选，不猜** |
| `search_source` | 源码内关键词搜索 | 关键词 |

另有一个**内置 `read`** 工具：当工具结果溢出落盘时，用于把溢出的内容取回。

> 各工具的返回结构、限额（行数/字节/超时）、以及内置 `read` 的落盘路径约定：**【待补充 T12】**
