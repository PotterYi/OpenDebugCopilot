## 7. 技术选型

### 7.1 已确认（DEMO 实际使用，见 08）

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 运行形态 | CLI / 本地 WebUI / Electron 桌面版 | 三者共用一套诊断编排 |
| 语言/运行时 | Node.js（ESM） | 全程 ESM |
| 桌面框架 | Electron | 主进程托管 HTTP 服务，随窗口生灭 |
| 内嵌浏览器 | WebContentsView（真实 Chromium） | 非 iframe / webview |
| 请求捕获 | CDP | 捕获请求；不做重放 |
| 浏览器自动化 | playwright-core + 无头 Edge（channel=msedge） | 打开页面、click/fill、`page.on` 捕获、`page.route` 注入 marker |
| 诊断引擎 | Claude Agent SDK 0.3.316 | 由 SDK 拉起 Claude Code；禁用内置工具、仅允许进程内 MCP、`maxTurns=24`、JSON Schema 结构化输出；2026-11-02 真实调用验证通过 |
| 工具通道 | MCP（进程内） | 5 个证据工具 + 内置 read（溢出落盘取回） |
| 路由控制 | webRequest 三钩子（改路由 / 抓预检头 / 补 CORS） | 按 URL 前缀逐条改道；自建壳 + dev server 代理为备用、可能淘汰 |
| 稳定性策略 | 硬闸门 + n=3 多次判定 | 记录一致/不一致/判不了；界面声明“一致不等于正确” |
| UI 技术栈 | **零框架**：手写 HTML + JS；Node http server + `/api/*` | 桌面复用同一套页面 |
| 桌面壳 | **Electron 45**（当前 45.2.1）；WebContentsView + CDP | 主进程托管 HTTP 服务；5 个 `dc:*` IPC 通道（名称待补 T20） |
| 浏览器自动化 | playwright-core（仅无头驱动） | 不用于桌面内嵌浏览器 |
| 日志关联 | marker：`dcprobe<随机hex>`；模式 body / header / both / none | 注入 JSON body 字段或请求头；无法注入时降级并披露 |
| 落盘等待 | 固定 sleep 1.2s | 实测链路延迟约 150ms；慢系统截断风险待评估（T18） |
| 报告脱敏 | 白名单投影后渲染 | 去绝对路径、头值、日志与源码原文 |
| 日志采集 | 纯读文件；readline 流式 + iconv-lite（GBK） | 编码自动/utf8/gbk；识别轮转、堆栈续行；每次调用全量线性扫 |
| 日志解析 | 预设（json-lines / logback / spring-boot / pipe / node）+ 自定义 regex；自动探测 >60% 命中且全可解析 | 探测失败直接报错，不猜 |
| 持久化 | **无数据库**：`configs/*.json`、`runs/<runId>/`；UI 态用 localStorage | 认证优先 `configs/agent-auth.json`（safeStorage 加密 Token / 环境变量引用），回退 `~/.claude/settings.json` |
| 工程结构 | `src/` 十模块 ESM，无构建 | core/evidence/tools/agent/driver/diagnose/doctor/report/ui/app |
| 诊断数据面 | 只读日志 + 源码 | 不做写入/修复落地 |

## 8. 安全与隐私

1. **数据边界**：源码、日志、请求数据仅存本机；唯一出站流量是发送给 LLM 的上下文包。
2. **发送前可控**：每次诊断前展示将要发送的内容摘要，可逐项剔除；敏感字段默认脱敏。
3. **脱敏规则**：统一 `core/redact.mjs` 识别 Authorization/Cookie/password/token/secret 等键名、`sk-ant-`/GitHub/AWS/JWT、Bearer/Basic、连接串账号密码与私钥块；作用于 MCP 工具结果、内置工具 PostToolUse 输出、证据包与追问快照、`db-queries/` 落盘、报告，以及 `result.json` 的请求/响应头（保留头名，敏感值替换为 `<redacted>`）。
4. **HTTPS**：不默认信任自签名证书；信任需用户显式操作并可按站点撤销。
5. **IPC 安全**：渲染进程禁用 nodeIntegration，通过白名单通道通信；拦截器脚本隔离。
6. **审计**：诊断会话记录“发送了哪些数据块”的摘要，供事后核对。
7. **Claude 凭据**：Token 只通过 safeStorage 加密写入 `configs/agent-auth.json`，或在环境变量模式中仅保存变量名；IPC/HTTP 永不回传明文。自定义/环境变量模式会注入子进程环境并隔离 `~/.claude/settings.json`，避免用户设置覆盖应用凭据。
8. **工作区备份**：原地模式只备份实际写入的文件，不再在启动时拷贝全部脏文件；保留/丢弃或恢复完成后删除 baseline，存在冲突时才保留以便重试。只读模式不在真实源码树 apply/compile/revert。
9. **进程清单出站（2026-11-14）**：`list_processes` 会把 `pid/ppid/name/startedAt` 与脱敏后的 `command` 随工具结果发送给 LLM 供应商。默认只列当前用户/会话；`command` 先经 `core/redact.mjs` 的 `redactCommand` 脱敏，再截断到 300 字符；不发送环境变量、完整 system properties 或其他用户进程。脱敏为尽力而为，自定义密钥格式仍可能遗漏；这是除请求/日志/源码之外新增的一类离开本机的数据。
10. **诊断前 Triage 出站（2026-11-14）**：用户选择的复现环境、影响范围、最近变更和可选备注会作为诊断上下文发送给 LLM；它们用于缩小假设范围，不是已验证事实。默认全部为“不确定”且可跳过；跳过时不发送虚构答案，报告明确标注“诊断前已跳过”。
11. **文件元数据出站（2026-11-15）**：`list_dir` / `stat_file` 会把相对路径、类型、大小和 mtime 随工具结果发送给 LLM；不读取文件内容，不返回绝对路径；`.env*`、密钥、`.git` / `.ssh` 等敏感路径在进入结果前被隐藏，列表中只给 hidden 计数。
12. **Git 元数据出站（2026-11-15）**：`git_status` / `git_log` / `git_diff` 会把分支、变更路径、提交 hash/日期/标题和受限 diff 发送给 LLM。默认不返回作者邮箱、commit body 或完整 patch；`git_diff` 默认 stat，完整 patch 必须显式指定单个非敏感文件，内容经 `core/redact.mjs` 脱敏并截断。Git 命令固定禁用 pager、外部 diff、textconv、fsmonitor 和 optional locks；历史中可能仍有已删除的敏感内容，脱敏为尽力而为。
13. **Maven 依赖元数据（2026-11-16）**：`maven_dependencies` 会把依赖坐标（group/artifact/version/scope/classifier）和可选 classpath 清单发送给 LLM；不发送本地仓库绝对路径或构建日志。Maven 命令结果缓存仅存在于当前诊断进程内存中（TTL 5 分钟，写入后清空），不落盘、不跨 run 复用。
14. **用量的可解释性（2026-11-16）**：`result.json` 的 `agent.usage` 记录逐模型 provider/canonicalModel/costBasis 与逐轮 cache 用量，仅保存在本机 run 目录；UI/报告展示缓存读/写与成本。非 firstParty provider 或 costBasis 非 list 时，成本标记为“估算”，不作为计费依据。
15. **自动修复重试的数据边界（2026-11-18）**：验证失败时，每轮发送脱敏后的失败命令、错误行、约 4KB 输出尾部、改动文件、上一轮及最近几次修复摘要给模型；不发送完整日志文件、绝对路径或密钥。`maxAttempts` 默认 3，`maxBudgetUsd`/`timeoutMs` 为整个循环总预算，`maxTurns` 仅为单次修复会话工具轮数；环境/依赖/权限/网络/超时、无文件变更、相同失败签名或预算耗尽时停止。历史 attempt 只保留最近 3 次摘要，报告只展示总次数和最后一轮。
16. **症状重放 fixture（2026-11-17）**：启用的 `workspace.replay` 会把捕获请求的方法、URL、安全的 Content-Type/Accept 头、body 与 origin 存入 `result.replayFixture`；不保存 Authorization/Cookie/token/API key。自动重放仅允许配置的 origin 与安全方法，响应仅用于本地签名比较；带认证头的请求一律回退人工确认。
17. **非代码动作的安全边界（2026-11-17）**：`actions` 中的命令和步骤会展示给用户但不自动执行；文本经 `redactSecrets` 脱敏。高风险/不可逆动作必须提示确认；P1 只允许白名单只读/构建验证命令运行，重启、部署、删除等写操作永不自动执行。
18. **构建探针根（2026-11-18）**：`buildProbeRoot` 默认源码根直接父目录，仅用于 `inspect_build_model`；只允许读 POM、`.idea/modules.xml`、`.iml` 及元数据，拒绝 `.idea/workspace.xml`、`.env*`、密钥、`.git` 和同级其他源码。路径经 realpath 校验，探针根必须是源码根祖先且不能是文件系统根。
19. **运行时事实的禁读与脱敏（2026-11-18）**：`runtime_facts` 在值脱敏之外有默认 deny 前缀（凭据/许可证/内网类），`workspace.runtimeFacts.denyPrefixes` 可追加且不能被 selector 绕过；命中返回 `denied:true`，不返回值或指纹；无 selector 的 groups/sampleKeys、通配 selector、comparePid/declaredFile diff 都过滤 denied。其余值仍经 `redactSecrets`，敏感值不返回指纹；结果分页并复用 spill/query_result。
20. **配置内容出站（2026-11-18）**：`search_source` 默认把 POM/YAML/properties/JSON 等配置文件的命中行（去空白、截断 300 字符）随工具结果发送给 LLM，`read_source` 可直接返回配置切片；内容统一经 `core/redact.mjs` 脱敏。路径限制在已授权源码根内并做 realpath/越界/敏感文件检查；lock 文件、压缩产物、source map、`.env*`、密钥和 `.git` 等不出现在搜索/读取结果中。脱敏为尽力而为，自定义密钥格式仍可能遗漏；如不希望发送配置，可在诊断时使用 `includeConfig=false`（Agent 侧）或缩小工作区源码根。
21. **排除假设的出站与展示（2026-11-18）**：`rejectedHypotheses` 中的假设文本、理由和证据引用会随模型输出保存在本机 `result.json`，并在报告/UI/CLI 展示。报告投影对文本做脱敏，证据 ref 只允许指向证据包中真实存在的路径；不额外读取证据包之外的文件。该字段用于审计与可证伪，不构成正确性证明；证据引用存在也只说明引用有效，语义是否真正否定假设仍需人工/症状验证。
22. **补丁写盘与 agent 同策略（2026-11-18）**：模型生成的补丁在预览、应用、撤销和批量操作时都经 `core/write-policy.mjs` 复查，与 agent Edit/Write 使用同一套规则：可写源码根内、realpath/符号链接、敏感文件、`.git`/`node_modules`、Git 忽略的构建产物均拒绝；已跟踪的 build/out 允许。应用阶段在原子写入/删除前再检查一次，避免预览后环境变化。拒绝信息只包含相对路径和原因，不返回绝对路径。
23. **项目诊断记忆（2026-11-18）**：`configs/diagnosis-memory.json` 只存本机，按源码/前端根 hash 分组，不跟 profile 绑定；笔记文本在写入和注入前经 `redactSecrets`，单条 300 字、整体 prompt 4KB/20 条。注入时明确标注“工具积累的历史前提，不是用户本次回答，也不是当前证据”，禁止写入 evidenceRefs；历史 runId/ref 只作线索。自动沉淀仅包含日志格式和通过 disclosure gate 的已排除假设，不保存模型结论/置信度；用户可删除/置顶，CLI `--no-memory` 可完全关闭。
24. **自动测试执行的本地风险（2026-11-18）**：自动探测到的 Maven/Gradle/Go/Python 测试会在沙箱或原地工作区执行，可能连接数据库、Redis、网络或写入测试数据；测试失败默认只做 warning，不隐藏修复、不触发自动修复，只有配置 `required:true` 才阻断。前端 test 脚本只提示不执行，避免 watch 模式挂起；`verifyRunTests=false` 可关闭自动测试，`verifyCommands` 可精确控制命令、phase、root 和 required。测试输出与构建输出一样截断并写入 run 目录，命令仍受现有超时/沙箱/原地会话约束。
25. **验证输出疑点的边界（2026-11-18）**：输出文本扫描只是成功命令的“疑点提示”，不是正确性证明；只匹配工具强信号，裸 `ERROR` 不触发。命中的行会进入本机 result.json/report/UI/CLI，可能包含日志/测试文本；沿用验证输出的脱敏与截断规则。离线跳过仅在命令显式带 `--offline`/`-o` 且输出含跳过关键词时提示；误报应通过配置命令或忽略 warning 处理，不会阻断应用/保留修改。
26. **只读凭据重放与元素复检（2026-11-18）**：`replay.allowCredentials=true` 仅对 GET/HEAD/OPTIONS 生效；Authorization/Cookie 等头只在内存传给 replay，不写入 fixture、result.json、report、日志或模型上下文。桌面端通过 Electron session.fetch 复用当前浏览器 Cookie；CLI 只能使用捕获到的头。写方法在本阶段拒绝。元素复检只在桌面端执行，页面/元素可能包含用户数据；before/after 截图和 JSON 存在本机 run 目录，不上传模型，状态变化只作为待确认证据。
27. **日志关联强度披露（2026-11-18）**：`logs.correlation` 的 strategy/strength/caveat 会随证据包发给模型，并写入本机 result/report；weak（time-window）明确提示可能混入其他请求。模型被要求说明关联依据，但系统仍以自动写入的结论前系统行为准，避免模型省略。关联强度不是正确性证明；business-id/trace 也可能误匹配，time-window 仍需人工复核。
28. **非代码动作执行边界（2026-11-18）**：动作 `command` 验证只允许构建/测试白名单命令，执行前需用户确认，输出只保留脱敏尾部并写入本机；部署、数据、重启、外部服务等命令不会自动执行，只能标记 confirmed/skipped/failed。`confirmed` 表示用户确认做过，不等于验证通过；只有实际命令/症状检查通过才是 passed。动作状态与截图/输出仅存本机，不自动发送给外部系统。

## 9. 非功能需求

| 指标 | 目标 |
| --- | --- |
| 冷启动到可操作 | < 3s |
| 单请求规则匹配 | < 5ms（P95，规则数 ≤ 200） |
| 拦截带来的额外延迟 | < 30ms（P95） |
| 日志采集吞吐 | ≥ 10MB/s 不丢行、不阻塞 UI |
| 日志查询（10 万行） | < 200ms |
| 诊断首字返回 | < 3s（流式） |
| 崩溃恢复 | 浏览器会话可重建；工作区/规则/会话不丢失 |
| 平台 | Windows 10+ / macOS 12+ / Linux（主要发行版） |
