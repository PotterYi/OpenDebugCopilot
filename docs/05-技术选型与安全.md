## 7. 技术选型

### 7.1 已确认（DEMO 实际使用，见 08）

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 运行形态 | CLI / 本地 WebUI / Electron 桌面版 | 三者共用一套诊断编排 |
| 语言/运行时 | Node.js（ESM） | 全程 ESM |
| 桌面框架 | Electron | 主进程托管 HTTP 服务，随窗口生灭 |
| 内嵌浏览器 | WebContentsView（真实 Chromium） | 非 iframe / webview |
| 请求捕获 | CDP | 捕获请求；不做重放 |
| 浏览器自动化 | playwright-core + 无头 Edge（channel=msedge） | 打开页面、click/fill、`page.on` 捕获、`page.route` 注入 marker |
| 诊断引擎 | Claude Agent SDK | 由 SDK 拉起 Claude Code 子进程，agent 循环上限 24 轮 |
| 工具通道 | MCP（进程内） | 5 个证据工具 + 内置 read（溢出落盘取回） |
| 路由控制 | webRequest 三钩子（改路由 / 抓预检头 / 补 CORS） | 按 URL 前缀逐条改道；自建壳 + dev server 代理为备用、可能淘汰 |
| 稳定性策略 | 硬闸门 + n=3 多次判定 | 记录一致/不一致/判不了；界面声明“一致不等于正确” |
| UI 技术栈 | **零框架**：手写 HTML + JS；Node http server + `/api/*` | 桌面复用同一套页面 |
| 桌面壳 | **Electron 45**（当前 45.2.1）；WebContentsView + CDP | 主进程托管 HTTP 服务；5 个 `dc:*` IPC 通道（名称待补 T20） |
| 浏览器自动化 | playwright-core（仅无头驱动） | 不用于桌面内嵌浏览器 |
| 日志关联 | marker：`dcprobe<随机hex>`；模式 body / header / both / none | 注入 JSON body 字段或请求头；无法注入时降级并披露 |
| 落盘等待 | 固定 sleep 1.2s | 实测链路延迟约 150ms；慢系统截断风险待评估（T18） |
| 报告脱敏 | 白名单投影后渲染 | 去绝对路径、头值、日志与源码原文 |
| 日志采集 | 纯读文件；readline 流式 + iconv-lite（GBK） | 编码自动/utf8/gbk；识别轮转、堆栈续行；每次调用全量线性扫 |
| 日志解析 | 预设（json-lines / logback / node）+ 自定义 regex；自动探测 >60% 命中且全可解析 | 探测失败直接报错，不猜 |
| 持久化 | **无数据库**：`configs/*.json`、`runs/<runId>/`；UI 态用 localStorage | 认证读 `~/.claude/settings.json` |
| 工程结构 | `src/` 十模块 ESM，无构建 | core/evidence/tools/agent/driver/diagnose/doctor/report/ui/app |
| 诊断数据面 | 只读日志 + 源码 | 不做写入/修复落地 |

## 8. 安全与隐私

1. **数据边界**：源码、日志、请求数据仅存本机；唯一出站流量是发送给 LLM 的上下文包。
2. **发送前可控**：每次诊断前展示将要发送的内容摘要，可逐项剔除；敏感字段默认脱敏。
3. **脱敏规则**：内置 Authorization、Cookie、Set-Cookie、password、token、secret 等键名规则 + 高熵字符串启发式。
4. **HTTPS**：不默认信任自签名证书；信任需用户显式操作并可按站点撤销。
5. **IPC 安全**：渲染进程禁用 nodeIntegration，通过白名单通道通信；拦截器脚本隔离。
6. **审计**：诊断会话记录“发送了哪些数据块”的摘要，供事后核对。

## 9. 非功能需求

| 指标 | 目标 |
| --- | --- |
| 冷启动到可操作 | < 3s |
| 单请求规则匹配 | < 5ms（P95，规则数 ≤ 200） |
| 拦截带来的额外延迟 | < 30ms（P95） |
| 日志采集吞吐 | ≥ 10MB/s 不丢行、不阻塞 UI |
| 日志查询（10 万行） | < 200ms |
| 诊断首字返回 | < 3s（流式） |
| 崩溃恢复 | 浏览器会话可重建；工作区/规则/会话不丢失 |
| 平台 | Windows 10+ / macOS 12+ / Linux（主要发行版） |
