# 13 M2 打包评估

> 文档集索引：[README.md](./README.md) ｜ 上篇：[12-M2验收清单.md](./12-M2验收清单.md) ｜ 下篇：—
>
> 结论：**M2 不交付安装包**，以 `npm run desktop` 运行源码版本；打包列为 T24，M3 再落地。

## 13.1 当前运行方式

```bash
npm install
npm run desktop
```

- 前提：Node ≥ 20、本机 Microsoft Edge（playwright-core 使用系统 Edge）
- 端口：UI 固定 7080；被占用时明确报错
- 配置：项目 `configs/`；诊断历史：项目 `runs/`

## 13.2 目标产物（M3 再做）

| 平台 | 形式 |
| --- | --- |
| Windows | NSIS 安装包 + portable 免安装 |
| macOS / Linux | 暂不承诺（先保证 Windows） |

electron-builder 配置草案：

```json
{
  "build": {
    "appId": "com.debugcopilot.app",
    "productName": "DebugCopilot",
    "files": ["src/**/*", "configs/default.json", "package.json"],
    "asarUnpack": [
      "node_modules/@anthropic-ai/claude-agent-sdk-win32-x64/**"
    ],
    "win": { "target": ["nsis", "portable"] }
  }
}
```

## 13.3 体积与依赖风险

| 项 | 说明 |
| --- | --- |
| Claude Code 二进制 | SDK 平台包约 **335MB**（`@anthropic-ai/claude-agent-sdk-win32-x64/claude.exe`），必须随包分发并 `asarUnpack` |
| playwright-core | 不下载浏览器，使用系统 Edge（无需打包浏览器） |
| Electron | 安装包基础体积约 100MB+；最终安装包预计 **400–600MB** |
| 固定端口 | 打包后仍固定 7080；需在安装/启动时给出占用提示 |

## 13.4 网络与工具链

- electron-builder 首次构建需要下载 `winCodeSign`、`NSIS` 等工具，来源常为 GitHub；
  当前网络不稳定时会失败。可配置镜像（`ELECTRON_BUILDER_BINARIES_MIRROR`）后重试。
- Electron 本体可从 npmmirror 获取（本次已用 `ELECTRON_MIRROR` 成功安装）。

## 13.5 推荐落地步骤（M3）

1. `electron-builder --dir` 产出未压缩目录，验证启动、IPC、内嵌浏览器、SDK 调用。
2. 验证打包后 SDK 能拉起 `claude.exe`（asarUnpack 路径正确）。
3. 再启用 NSIS/portable；最后做一次干净机器安装测试。
4. 打包阶段补齐：固定端口占用提示、错误上报、版本号与更新策略。

## 13.6 实施结果（2026-11-03）

| 项 | 结果 |
| --- | --- |
| 构建 | `electron-builder --win --dir` 成功，输出 `dist/win-unpacked` |
| 体积 | 未压缩目录约 **693MB**（含 335MB `claude.exe`） |
| 打包冒烟 | `DebugCopilot.exe --smoke --smoke-out ...` 通过：`hasDc/uiReady/ok=true` |
| SDK | `app.asar.unpacked/.../claude-agent-sdk-win32-x64/claude.exe` 存在 |
| 配置路径 | 开发：项目 `configs/`；**打包后：`%APPDATA%/DebugCopilot/configs`**（runs 同理） |
| 签名 | 未配置证书，跳过签名 |
| 图标 | 暂用 Electron 默认图标 |
| 脚本 | `npm run dist:dir`（目录版）、`npm run dist:win`（NSIS/portable，待首次验证） |

> 打包后 UI 端口仍固定 7080；配置与历史写用户目录，避免 asar 只读。

## 13.7 决策

- M2：源码运行 + tag `v0.2.0`，不阻塞功能验收。
- T24：`--dir` 已打通；NSIS/portable 安装包与签名/图标留待后续。
