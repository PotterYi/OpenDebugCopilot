# 01 概述与使用场景

> 文档集索引：[README.md](./README.md) ｜ 上篇：— ｜ 下篇：[02-功能需求.md](./02-功能需求.md)

## 1. 概述

### 1.1 背景与痛点

后端 / 全栈工程师在联调和排障时，常见问题：

1. **环境切换成本高**：本地后端、测试环境、线上后端之间来回切换，需要改配置、改 host、重启服务。
2. **链路割裂**：浏览器 DevTools 看请求、终端看日志、IDE 看源码，三个窗口来回对照，靠人脑做时间对齐和 traceId 对齐。
3. **定位慢**：页面报错只能看到一个 HTTP 500 / JS 异常，真正的异常堆栈在服务端日志里，需要逐层翻找。
4. **经验不可沉淀**：一次排查过程无法复用，同类问题重复投入。

### 1.2 产品定位

**DebugCopilot 是一款运行在本地的后端开发辅助软件**：把「内嵌浏览器 + 流量路由控制 + 请求/日志/源码聚合 + AI 诊断」收敛到一个工作台里，帮助后端或全栈工程师**快速定位并解决项目中的问题**。

一句话描述：

> 在软件内打开前端页面，用规则把指定接口导流到本地后端，页面一报错，就能结合请求、日志、源码与问题描述，直接给出可执行的定位结论和修复方案。

**已确认的形态（见 08）**：同一套诊断编排，提供三种入口——CLI、本地 WebUI、Electron 桌面版。
桌面版通过内嵌 Chromium 承载页面；CLI / WebUI 形态不内嵌浏览器。

### 1.3 目标用户

| 角色 | 典型诉求 |
| --- | --- |
| 后端工程师 | 只关注个别接口，希望前端页面把流量打到自己本地的服务上 |
| 全栈工程师 | 前后端一起改，需要快速在链路上定位到底是哪一层出问题 |
| 测试 / 值班同学 | 复现问题后快速产出带证据的排查报告 |

### 1.4 设计原则

1. **本地优先**：源码、日志、请求数据默认不出本机；对外发送的内容可预览、可脱敏。
2. **不侵入、不改代码**：通过浏览器层拦截与代理实现路由控制，前端/后端代码零改造。
3. **证据可追溯**：所有诊断结论必须挂靠到具体证据（请求 ID、日志行、file:line），拒绝“黑盒猜答案”。
4. **可解释的自动化**：自动聚合上下文，但保留用户介入点（规则启停、上下文增删、追问）。
5. **渐进式能力**：先跑通“路由 + 捕获 + 对话定位”的最短闭环，再逐步增强日志、源码、自动诊断。

### 1.5 非目标（当前阶段不做）

- 不做线上生产环境的全链路 APM / 监控平台。
- 不做代码托管、CI/CD、部署发布。
- 不做通用 Web 调试器（不与 Chrome DevTools 全量功能对标）。
- 不做多人实时协作编辑（报告分享形态见 §11 Q7）。

## 2. 核心场景与用户旅程

### 2.1 场景 A：本地联调，部分接口走本地后端

前置：本地已启动前端 dev server（如 http://localhost:5173）与后端服务（如 http://127.0.0.1:8080）。

| 步骤 | 用户动作 | 系统行为 |
| --- | --- | --- |
| 1 | 新建工作区，填入前端地址、后端地址、日志目录、源码目录 | 校验连通性，生成工作区配置 |
| 2 | 在「流量规则」里加一条：POST /api/order/** → 转发到本地 8080 | 规则进入启用状态并持久化 |
| 3 | 在内嵌浏览器中打开前端页面 | 浏览器加载页面，CDP 会话就绪 |
| 4 | 页面触发请求 | 命中规则的请求被重写到本地后端，未命中的请求按原样发出 |
| 5 | 页面出现报错 | 捕获请求/响应、console 错误并提示 |
| 6 | 在对话框描述“下单失败了” | 聚合上下文 → 诊断 → 输出证据链与修复建议 |

### 2.2 场景 B：复现并定位服务端异常

1. 页面 500 → 系统自动记录该请求与响应体、时间戳。
2. 系统按时间窗（±N 秒）与 traceId 从日志目录拉取相关日志，提取异常堆栈。
3. 堆栈帧映射到源码 file:line，打开源码片段。
4. AI 结合「问题描述 + 请求摘要 + 日志摘要 + 源码片段」输出：根因假设、证据、修复建议、验证步骤。

### 2.3 使用方式（当前 DEMO 已跑通的主流程）

```
启动软件 → 填写前端/后端地址端口 → 填写日志位置与源码位置
        → 内嵌浏览器访问前端页面 → 通过路由控制部分接口访问本地后端
        → 页面报错 → 捕获请求信息 + 对话描述问题 → 快速定位 + 给出方案
```

当前 DEMO 的差异（详见 08）：请求**不回放**，在请求列表中点选某一条即以该条为诊断对象；
路由控制提供两种模式（复用 dev server 代理 / webRequest 钩子按前缀改道）。
